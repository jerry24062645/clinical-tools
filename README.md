# Auto Clinical Lab v6.9.3

## 新增判讀
- Estradiol (E2), pg/mL
- FSH, mIU/mL
- Hb electrophoresis：Hb-F / Hb-A / Hb-A2
- Hb EP Comments：保留院內報告原文
- Urine Protein：Negative → `PRO (-)`；Positive → `PRO (+)`

## 輸出範例
- `• Gonadal: E2 26.8 pg/mL; FSH 81.5 mIU/mL`
- `• Hb electrophoresis: Hb-F 0.0%; Hb-A 97.8%; Hb-A2 2.2%; Comments: ...`
- `• Urine: Clear; Glu (-); PRO (-); OB (-); RBC 0-2/HPF; WBC 0-5/HPF; EP cell 0-5/HPF; Bacteria (-); Cast 0-2/LPF; pH 5.5`
