# Clinical Tools

### 🩺 Auto Clinical Lab

**自動整理 EMR 檢驗與檢查報告，快速產生臨床摘要。**

支援 OPD / ER / Inpatient、H/L、自動整理常用 Lab、Urine、Culture、Pathology、Echo、CXR、PVR/ABI、InBody 等資料。

👉 [**Auto Clinical Lab Bookmarklet**](https://jerry24062645.github.io/clinical-tools/emr_lab_bookmarklet.html)

進入後，將 **⭐ Auto Clinical Lab** 按鈕拖曳到瀏覽器書籤列。使用時在 HIS 頁面點該書籤即可。
