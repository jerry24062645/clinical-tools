# Clinical Tools

### 🩺 Auto Clinical Lab

**自動整理 EMR 檢驗與檢查報告，快速產生臨床摘要。**

支援 OPD / ER / Inpatient、H/L、自動整理常用 Lab、Urine、Culture、Pathology、Echo、CXR、PVR/ABI、InBody 等資料。

👉 [**Auto Clinical Lab Bookmarklet 安裝頁**](https://jerry24062645.github.io/clinical-tools/emr_lab_bookmarklet.html)

> 安裝一次即可：進入安裝頁後，把 **⭐ Auto Clinical Lab** 拖曳到瀏覽器書籤列。之後在 HIS 頁面直接點書籤列的 **Auto Clinical Lab** 才會讀取目前 HIS；不要直接點安裝頁上的按鈕。
