# Clinical Tools v6.5.2

Auto Clinical Lab Bookmarklet。

- 自動讀取 Lab / Urine / Echo / CXR / PVR-ABI / InBody 等資料
- PVR aliases：`心內動脈分段血流及壓力之測定PUR(Pulse volume recording)` 與 `四肢血流探測, 壓力測量並記錄` 視為同一檢查
